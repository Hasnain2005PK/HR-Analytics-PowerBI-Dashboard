# HR Analytics Dashboard

An interactive HR Analytics dashboard built with **Microsoft Power BI** to analyze employee attrition, workforce demographics, departments, job roles, and other key HR metrics.

## 📊 Project Overview

This project focuses on transforming HR data into an interactive dashboard that helps understand workforce trends and identify patterns related to employee attrition.

The dashboard provides both a high-level overview and detailed employee-level information.

## 🎯 Dashboard Pages

### 1. HR Overview

The Overview page provides a summary of the organization's workforce, including:

* Total Employees
* Employee Attrition
* Attrition Rate
* Average Employee Age
* Department-wise Attrition
* Job Role Analysis
* Gender and Age Distribution
* Education and Marital Status
* Other HR performance indicators

### 2. Employee Details

The Employee Details page provides a more detailed view of individual employees and allows HR-related information to be explored using interactive filters.
